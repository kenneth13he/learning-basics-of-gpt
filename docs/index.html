The dashed line is the counting model's loss. The network can't beat it, only match it. Regularization pulls W toward 0, the neural-net version of adding fake counts: turn it up and every row flattens out.

Loss: how surprised each model is by real names

Loss is the average of −log(probability the model gave the real next letter), measured on names the MLP and WaveNet never trained on. Lower is better.
